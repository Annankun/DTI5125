=== SUBMISSION FLOW (from GreenShield+ app/web) ===

1. Log in to GreenShield+ (app.greenshieldplus.ca)
2. Click "Submit a claim"
3. Select claim category from dropdown (129 categories)
   - Flat list, no subcategories
   - No description or help text per category
   - User must know the correct category name
4. Select or search provider (shows "Recently Visited Providers")
5. Enter amount and date
6. Submit

=== THE PROBLEM (why our chatbot is needed) ===

- 129 categories in a flat dropdown with no explanations
- Many categories are similar (e.g., 7 types of Compression Stockings)
- Users describe services in natural language but must map to exact category names
- No guidance from the system on which category to pick
